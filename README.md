# 河北工业大学学习资料知识库

这是给河北工业大学同学攒的一个资料库。里面有期末复习资料、竞赛资料和电子课本，能帮上忙的就留下来，方便后来的人找。

## 为什么有这个仓库

以前一到期末，找资料总得四处问：翻群聊、逛二手群、和同学交换。花了不少时间，最后拿到的还不一定是真题，也不一定用得上。

既然已经有人筛过一遍、踩过一些坑，不如把能用的资料留在这里。下次有人找资料时，少走一点弯路就够了。

我学的是机械电子工程，所以现在的内容难免有专业限制。不同专业的同学如果愿意补充，这个库才会慢慢像个样子。

## 现在特别缺资料

仓库刚起步，资料确实还不多。如果你手里有自己用过、觉得靠谱的材料，欢迎发来：

- 期末真题、回忆题与复习资料
- 电子课本、课程讲义和习题资料
- 竞赛入门资料、经验整理
- 课程实验、课程设计等学习参考材料

不会用 GitHub 也没关系，直接微信把资料或线索发给我就行。我会慢慢整理，收录后也会在[贡献者名单](CONTRIBUTORS.md)里记下这份心意。

## 资料放在哪里

- [学科](学科/)：课程复习资料、电子课本、习题等。
- [竞赛](竞赛/)：竞赛资料和一些入门信息。
- [知识](知识/)：平时整理的书和其他知识性材料。

## 使用前看一眼

资料大多由同学搜集或整理，难免有缺漏，也可能和现在的课程安排不完全一致，用之前自己核对一下。真题、答案和课程材料只用于学习复习，别拿去做违反课程规定的事。

如果有版权或内容问题，联系我处理。

## 想补充资料

发资料时，能顺手写一下课程名称、适用的学期或年份、资料类型和大概用途就很好。这样后面整理起来不容易乱，别人找资料也更快。
