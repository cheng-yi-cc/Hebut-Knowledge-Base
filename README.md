# 河北工业大学学习资料知识库

面向河北工业大学同学的学习资料整理仓库，主要收集期末复习资料、竞赛资料和电子教材等可供学习参考的材料。

## 为什么建立这个仓库

期末找资料往往很费时间：群里信息零散，来源难以确认，反复交换也未必能找到真正有用的内容。既然已经有人花时间筛选和整理过，就希望把这些资料留下来，少让后面的同学再走一遍弯路。

这个仓库由机械电子工程专业同学发起，也欢迎不同专业的同学一起完善。资料不一定覆盖所有课程，但希望能一点点积累成对后来者真正有帮助的东西。

## 正在征集资料

仓库目前仍在建设，现有资料还比较少，特别需要大家一起补充。欢迎分享自己整理或用过、且确认有参考价值的资料：

- 期末真题、回忆题与复习资料
- 电子教材、课程讲义与习题资料
- 竞赛入门材料、经验整理与资料合集
- 课程实验、课程设计等可供学习参考的材料

不熟悉 GitHub 也没有关系，可以直接通过微信把资料或线索发给维护者；后续会统一整理并注明贡献。

## 资料分类

- [学科](学科/)：各课程的复习资料、电子教材、习题与学习参考材料。
- [竞赛](竞赛/)：竞赛相关的资料、入门信息与经验整理。
- [知识](知识/)：学习过程中整理的书籍和其他知识性资料。

## 使用说明

- 本仓库资料仅供个人学习与复习参考，请结合课程要求和自身情况使用。
- 真题、回忆题和答案等资料可能存在缺漏或与当前教学安排不一致，请自行核对。
- 请遵守学校课程考核与学术诚信要求，不将资料用于违规用途。
- 仓库尊重原作者与权利人的合法权益；如有版权或内容问题，请联系维护者处理。

## 如何参与

提交资料时，如方便请一并说明课程名称、适用学期或年份、资料类型和简要用途，能帮助后续同学更快找到需要的内容。资料经确认并整理后，将登记在[贡献者名单](CONTRIBUTORS.md)中。
