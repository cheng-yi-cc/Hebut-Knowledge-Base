使用方法 
共K1 K2 K3 3个按键
K3 单击 用于切换时间、温度显示和秒表功能菜单间切换
当菜单为秒表时 单击K1 开/关秒表 长按K1秒表清0
长按K3 进入/退出时间调整菜单
当菜单为时间调整时 单击K3 选择时/分/秒准备进行调整 单击K1 当前位+1 单击K2当前位-1 时间调整完毕后
长按K2保存当前时间值 但LED灯闪烁一次时，则表示校时成功
