## 第一类 · 高频（计算题必用 + 课件重点推导）

### 第1章 物理属性

| 公式 | 教材位置 | 易错字母 | 适用场景 |
|---|---|---|---|
| 牛顿内摩擦定律 τ = μ·(du/dy) | 印008–009 (1-9)(1-10) | τ切应力(Pa)；μ动力黏度(Pa·s)；du/dy速度梯度。线性分布时 du/dy = U/h（U板速、h间隙） | 平板、轴承间隙、圆盘间隙等求黏性切应力/摩擦力/力矩。摩擦力 F=τ·A，功率 P=F·U |
| 运动黏度 ν = μ/ρ | 印009 (1-11) | ν(m²/s)；别和 μ(Pa·s) 混。雷诺数里用 ν | 给 μ、ρ 求 ν；雷诺数计算 |

> 黏性例题套路：线速度 U = rω = r·πn/30（n为r/min）；圆盘力矩 M = ∫τ·2πr·r dr = πμωd⁴/(32δ)。

### 第2章 流体静力学

| 公式 | 教材位置 | 易错字母 | 适用场景 |
|---|---|---|---|
| 静力学基本方程 **p = p₀ + ρgh** | 印022 (2-10) | p₀液面压强（开口取大气=0相对压强）；h从液面**往下为正**的深度；ρ为该层液体密度 | 测压管、压差计、同种液体内任意两点压差。复式压差计逐个等压面联立 |
| 平衡微分方程全微分式 dp = ρ(f_x dx + f_y dy + f_z dz) | 印020 (2-6) | f_x,f_y,f_z为**单位质量力**分量(m/s²)，含惯性力时记得加负号 | 相对平衡（加速、旋转）求压强场、液面方程的通用起点 |
| 等加速直线运动 p = p₀ − ρ(ax + gz)；等压面 (a/g)x + z = C | 印033 (2-23)(2-25) | a加速度方向取 +x；液面**斜率 = −a/g**（朝加速反方向抬高） | U形管/容器水平加速，求两侧液面高差 Δh = (a/g)·L |
| 等角速旋转 自由液面 z = z₀ + ω²r²/(2g)；任意点 p = p₀ + ρgh | 印034–035 (2-31)(2-32) | ω单位 rad/s（**ω = πn/30**，n为r/min）；r到转轴距离；抛物面**顶点到边缘升高 = ω²R²/2g = ω²D²/8g** | 旋转容器求转速、液面形状、是否溢出/触底 |
| **平面壁总压力 P = ρg·h_c·A = p_c·A** | 印027 (2-15) | **h_c = 形心的竖直淹深**（不是斜距！斜放时 h_c = y_c·sinα）；A受压面积 | 矩形/圆形闸门、平板挡水求总压力 |
| **压力中心 y_D = y_c + I_c/(y_c·A)** | 印027–028 (2-17) | y_c、y_D是**沿斜面到液面交线的距离**；I_c为绕**形心轴**的惯性矩（查表2-2，别用底边轴） | 求总压力作用点位置 |
| 几何特性表（表2-2） | 印028 表2-2 | 矩形 A=bh, y_c=h/2, I_c=bh³/12；圆 A=πd²/4, I_c=πd⁴/64；三角 I_c=bh³/36 | 配合压力中心公式取 I_c、A、y_c |
| **曲面水平分力 P_x = ρg·h_c·A_x** | 印030 (2-19) | A_x为曲面在**铅垂面上的投影面积**；h_c为该投影面形心淹深 | 曲面/半球盖/弧形闸门，水平方向受力 |
| **曲面垂直分力 P_z = ρg·V（压力体）** | 印030 (2-20) | V为**压力体体积**；方向由压力体是实(向下)还是虚(向上)判定 | 曲面垂直受力；压力体=曲面+铅垂投影线+液面 |
| 曲面合力 P = √(P_x² + P_z²)；tanθ = P_z/P_x | 印030 (2-21)(2-22) | θ为合力与水平线夹角 | 求曲面总压力大小与方向 |

### 第3章 流体动力学

| 公式 | 教材位置 | 易错字母 | 适用场景 |
|---|---|---|---|
| 欧拉法加速度 a = ∂u/∂t + (u·∇)u（=当地+迁移） | 印046 (3-6) | a_x = ∂u_x/∂t + u_x∂u_x/∂x + u_y∂u_x/∂y + u_z∂u_x/∂z；恒定流当地项=0但迁移项≠0 | 已知速度场 u_x,u_y 求某点加速度 |
| 流线方程 dx/u_x = dy/u_y = dz/u_z | 印048 (3-11) | 同一时刻、t视为常数；与迹线(3-10)区别在t是否变 | 给速度分布求流线方程 |
| **连续性微分方程（不可压）∂u_x/∂x + ∂u_y/∂y + ∂u_z/∂z = 0** | 印148 (6-1) | 散度=0才连续；≠0则不存在/不连续 | 判断给定速度场是否满足不可压连续 |
| **总流连续性 Q = v₁A₁ = v₂A₂** | 印051 (3-16) | v为断面**平均流速**；圆管 A=πd²/4，故 v₂ = v₁(d₁/d₂)² | 变径管求流速；分汇流 ΣQ入 = ΣQ出 |
| 断面平均流速 v = Q/A = (1/A)∫u dA | 印050 (3-14) | 区分点速度 u 与平均流速 v | 已知流速分布积分求平均流速 |
| 理想流体元流伯努利 z + p/(ρg) + u²/(2g) = C | 印054 (3-22) | 三项＝位置/压强/速度水头；理想流体、沿同一流线 | 推导基础、理想流速估算 |
| **实际总流伯努利 z₁+p₁/ρg+α₁v₁²/2g = z₂+p₂/ρg+α₂v₂²/2g + h_w** | 印060 (3-30) | 基准面统一；p同取相对或绝对压强；α动能修正系数(层流2,紊流≈1)；**h_w水头损失只加在下游侧** | 管流核心方程：求压强、流速、流向、水头损失、水泵扬程 |
| **动量方程 ΣF_x = ρQ(β₂v₂ₓ − β₁v₁ₓ)** | 印064 (3-34) | 矢量式，**带正负号取投影**；ΣF含压力+重力+壁面反力 R；β动量修正系数≈1；出口减进口 | 射流冲击平板、弯管、喷嘴受力 |

> 文丘里流量计（作业3.15、题库5）：伯努利+连续性联立，Q = μ·A₂·√[2(p₁−p₂)/(ρ(1−(d₂/d₁)⁴))]，μ为流量系数。差压由压差计读数换算。

### 第4章 黏性管流（课件 L6–L7 重点推导）

| 公式 | 教材位置 | 易错字母 | 适用场景 |
|---|---|---|---|
